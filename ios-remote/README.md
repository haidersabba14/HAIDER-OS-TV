# HAIDER Remote 📱
New SwiftUI iPhone remote for HAIDER OS TV. Six-digit pairing code, buttons for D-pad, OK, Back, Home, Volume.

Build unsigned IPA in GitHub Actions > Build HAIDER Remote IPA. **Unsigned IPA cannot be installed** until signed with a valid iOS certificate and provisioning profile matching the bundle identifier.

The TV must run HAIDER OS TV with its Phone Remote receiver enabled. Keep TV and phone on the same trusted Wi-Fi. This receiver controls HAIDER OS TV only; it does not elevate permissions or fully control Haier system UI.
